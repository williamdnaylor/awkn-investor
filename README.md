## Key Model Facts (as of July 2026)

- **AWKN Residences:** 75 homes on 9 acres - 15 domes ($3,000/mo), 15 modern cabins 688 sf ($2,500/mo), 25 A-frames 888 sf ($3,000/mo), 25 grand cabins 1,111 sf ($3,300/mo). WiFi and water included; residents pay electric.
- **Build:** single phase, all homes online **January 2028**. Construction raise ~$10.9M ($6.9M senior debt / $4.0M LP equity at 8% pref, 70/30 above pref).
- **Stabilized:** $228K/mo revenue at 95% occupancy, ~$74.5K/mo OpEx, **$1.84M NOI**, **~$27.1M value** at 6.8% cap, 3.34x DSCR.
- **Land:** 15-yr ground lease at $8K/mo with a $10M purchase option before year 8 (Residences carry $7M / 70%).
- **Seed round:** $500K at an $8M valuation cap for the operating business (Within Center + AWKN Ranch).

## Editing the Decks

1. Each deck is a single self-contained `index.html` (inline CSS/JS, Google Fonts via CDN).
2. Edit directly on GitHub (pencil icon) or locally, commit to `main`, and GitHub Pages redeploys automatically in 1-2 minutes.
3. **Image filenames matter:** the Residences deck references `images/modern-cabin-688.jpg`, `images/a-frame-888.jpg`, `images/grand-cabin-1111.jpg` (the 1,111 photo is also the hero). Keep names exact when replacing photos.
4. All pages carry `noindex, nofollow` - reachable by direct link, hidden from search engines. Keep that tag on any new page.
